# Skill: CV Tailoring & ATS Optimization

**Purpose:** Tailor candidate CV for a specific posting while maintaining strict truthfulness (Zero Fabrication).

## Absolute Rules:
- **NO FABRICATION:** Never invent experience, companies, metrics, degrees, or certifications.
- **TAILORING:** Reorder sections, highlight matching tech (e.g. Azure, Docker, GitHub Actions, Rails, Next.js), select relevant achievement bullets, adapt summary, and format as clean ATS-readable single-column text or Swiss HTML.
