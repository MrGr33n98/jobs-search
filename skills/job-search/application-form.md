# Skill: Application Form Answer Drafts

**Purpose:** Draft answers for screening and application form questions.

## Question Classification:
- **`SAFE_FACTUAL`:** Name, contact info, portfolio links, verified technical stack experience. -> **Drafted automatically**.
- **`HUMAN_CONFIRMATION_REQUIRED`:** Salary expectation, work authorization/visa status, availability start date, legal declarations, demographic surveys. -> **Flagged for human input**.
